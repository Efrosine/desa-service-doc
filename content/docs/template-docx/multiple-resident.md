# Multiple Resident

Gunakan namespace bernomor:

~~~text
${resident_1.name}
${resident_2.name}
${resident_3.name}
~~~

Untuk family:

~~~text
${family_1.kk_number}
${family_2.kk_number}
${family_3.kk_number}
~~~

Jika `additional_residents = 2`, total resident adalah 3.

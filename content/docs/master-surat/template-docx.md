# Template DOCX

Template adalah file Microsoft Word `.docx`.

Upload melalui jenis surat → **Template Surat** → **Unggah Template**.

Satu jenis surat dapat memiliki beberapa versi tetapi hanya satu template aktif.

Jika template aktif dihapus, versi tertinggi yang tersisa otomatis aktif. Jika tidak ada template, jenis surat tidak memiliki template aktif.

Request lama tetap dipertahankan. Jika template yang pernah digunakan dihapus, request menampilkan **Template tidak tersedia**.

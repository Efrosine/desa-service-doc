# Mengedit Letter Request

Jika template lama masih ada, template tersebut dapat digunakan.

Jika template lama dihapus:

1. sistem membaca jenis surat;
2. mencari template aktif terbaru;
3. memilihnya otomatis;
4. tetap menampilkan pilihan template lain;
5. mempertahankan field form yang masih cocok;
6. menyimpan request dengan template baru;
7. generate ulang dokumen.

Jika jenis surat juga dihapus, tidak ada fallback template. Request tetap dipertahankan sebagai history.

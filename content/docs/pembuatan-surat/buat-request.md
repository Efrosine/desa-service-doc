# Membuat Letter Request

## Jenis Surat

Pilih jenis aktif. Label berbentuk `CODE - Nama`. Setelah dipilih, template aktif terbaru otomatis dipilih.

## Template

Template tetap dapat diganti manual. Option menampilkan `Nama Template — Versi N`.

## Data Penduduk

Pilih resident sesuai kebutuhan. Sistem memvalidasi jumlah, duplikasi, dan ketersediaannya.

## Institusi

Jika jenis surat menggunakan data source `institution`, field institusi ditampilkan dan wajib diisi.

## Data Tambahan

Field berasal dari `form_schema` template.

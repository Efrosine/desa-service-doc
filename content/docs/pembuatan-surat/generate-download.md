# Generate dan Download

Generator menggunakan request, snapshot resident/family, dynamic form, institution snapshot bila ada, dan template DOCX.

Output: `.docx`. File hasil berada pada storage aplikasi.

Jika generated file hilang tetapi template tersedia, sistem dapat generate ulang saat download. Jika template juga hilang, generate ulang tidak dapat dilakukan.

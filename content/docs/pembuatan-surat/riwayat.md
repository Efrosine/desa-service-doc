# Riwayat dan Penghapusan Master

Letter Request dipertahankan sebagai history.

## Letter Type dihapus

Request tidak ikut dihapus. `letter_type_id` menjadi `NULL` dan daftar menampilkan **Jenis surat tidak tersedia**.

## Template dihapus

Request tidak ikut dihapus. `letter_template_id` menjadi `NULL` dan daftar menampilkan **Template tidak tersedia**.

Snapshot resident/family menjaga data historis dari perubahan master penduduk.
